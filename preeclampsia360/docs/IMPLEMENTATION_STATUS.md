# Implementation status — development handoff

This increment adds API foundations for workspace/navigation metadata, questionnaire section revision capture, patient timeline, referral creation and guarded state transitions, offline sync event ingestion, and an OCR preview endpoint. It also adds migration 0004.

## Important limitations / not production-ready
- Migration 0004 must be run manually in Supabase before the new routes can use `sync_events` and `questionnaire_revisions`.
- First System Administrator bootstrap still requires a one-time secure operational procedure and a provisioned Supabase service-role secret. Do not expose it in Flutter or chat.
- The current ID/PIN auth module and provisioning endpoint require further security review and testing; the existing provision endpoint is System-Admin-only and does not yet implement full THC→CHC→PHC delegated provisioning.
- The offline endpoint currently accepts and deduplicates queued events; it does not yet replay every event type into its target table or implement conflict-resolution semantics. Treat `accepted` as queued, not clinically committed.
- OCR endpoint is a preview adapter. Tesseract must be installed in the host image to use it; otherwise mobile ML Kit OCR should provide text/candidate values. Human verification is mandatory. OCR is not a medical device connection.
- Referral state transitions are enforced in the API, but the transition matrix and receiving/origin roles require clinical and operational approval.
- Flutter screens in this increment are role-oriented navigation scaffolds. Complete data-bound forms, offline persistence, camera permissions, tests, accessibility review, and device QA remain to be completed.
- No clinical thresholds, triage recommendations, or diagnoses are generated by this increment.

## Files added in this work increment
- `backend/app/workflows.py`: workspace metadata, structured questionnaire revision writes, patient timeline, referral create/list/transition.
- `backend/app/sync.py`: idempotent offline event inbox endpoint and sync status.
- `backend/app/ocr.py`: image upload OCR preview adapter; worker confirmation required.
- `backend/scripts/bootstrap_admin.py`: one-time operator-run System Administrator bootstrap script (requires migration 0004 and secrets configured in a trusted terminal).
- `flutter_app/lib/features/workspace/workspace_screen.dart`: role-oriented premium navigation hub scaffold.
- `flutter_app/lib/features/questionnaire/antenatal_questionnaire_screen.dart`: guided questionnaire capture UI shell mapped to supplied proforma sections.

The questionnaire UI currently keeps draft values in memory only; persistent encrypted local storage and sync queue integration are not complete. The app screen is a UI scaffold, not a finished production workflow.
